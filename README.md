# Greenhouse temperature control system

Simulation of an automatic system for the control of a greenhouse using an ESP32 microcontroller, managed from a mobile phone using a Telegram bot.

### Main idea:
Explore automation and hardware control concepts.


### Technologies used:
- ESP32
- C++ (firmware)
- Wokwi (circuit simulation)
- VS Code
- Electronic components: DHT22, OLED SSD1306, encoder, LEDs
- Telegram (For remote control via a bot


### Architectural aspects:
- Embedded system with its own control logic
- Separation of sensors, processing, and output
- Complete circuit simulation in a virtual environment
